Purpose

This document defines the business-facing software and hardware requirements for the ACRON Real-Time Machine Monitoring & Mold Tracking System (RTMS). It provides a clear delivery scope, approval-ready expectations, and a practical reference for client sign-off and operational delivery.

2

Project Overview

ACRON RTMS is a real-time machine monitoring and mold tracking platform designed for plastic injection molding and industrial manufacturing plants. By connecting shop-floor machine controllers, high-temperature RFID mold tags, fixed RFID readers, a local Central Server, and cloud database backup, RTMS gives complete operational visibility into factory production, mold usage, and overall equipment efficiency.

The system enables clear operational transparency across plant machinery, mold lifecycle history, real-time event alerts, and production accounting from trial runs to full commercial manufacturing.
3

Real-Time Machine Monitoring

RTMS Machine-Level & RFID Hardware

The shop floor hardware setup guarantees reliable machine data collection and durable mold tracking in harsh industrial environments:

RTMS Machine Controller & Modules
  • Industrial PLC base controller with integrated 24V DC power regulation.
  • Network communication interface for central server data connection.
  • Digital input channels for counting production pulses and machine cycles.
  • Analog input modules for monitoring machine signals (such as pressure and temperature sensors).
  • DIN-rail power supply, base mounting hardware, and interconnection accessories.
RFID Reader & Mold Identification Hardware
  • Industrial fixed RFID readers with dedicated directional antennas.
  • Heavy-duty mounting brackets and industrial cables.
  • High-temperature metal-mount RFID tags rated up to 200°C attached directly to molds.
  • Durable industrial enclosure protection for factory floor longevity.
6

Machine-Level Implementation & Commissioning

Machine-level deployment follows a clear 9-stage engineering workflow across all factory floor machinery:

  1. Hardware Identification: Cataloging all machine units, controllers, sensors, and RFID readers.
  2. Physical Connections: Mounting controller enclosures, power supplies, and signal connection blocks.
  3. PLC Code Installation: Setting up controller logic to record production pulses and machine sensor signals accurately.
  4. RFID Hardware Installation: Positioning RFID readers and antennas near mold mounting positions for reliable detection.
  5. Power / Cable Connections: Routing power cables, signal wiring, and protective conduits across each machine.
  6. Machine Data Acquisition: Testing real-time detection of machine cycles, active states, and operational signals.
  7. Server Data Deployment: Connecting machine controllers to transmit data directly to the Central Server.
  8. Testing & Commissioning: Verifying accurate mold tag reading up to 200°C and machine pulse counts before final handover.
  9. Final Sign-Off: Conducting live testing across working machines for complete plant verification.

Security, Data Integrity & Access Control

The platform protects business data and ensures smooth plant operations through standard security measures:

  • Role-Based User Permissions: User accounts are assigned specific permissions (Administrator, Manager, Supervisor, Engineer) so users only see authorized screens.
  • Protected Local Plant Network: Machine controllers operate on a isolated local factory network for plant safety.
  • Offline Data Safeguard: Real-time data is saved on the Central Server first, preventing data loss if internet connectivity drops.
  • Secure Remote Management: Encrypted web connections protect remote dashboard logins and cloud reporting data transfers.
12

Out of Scope

  • Robotic automated physical mold changing mechanisms.
  • Direct modification of physical machine safety interlocks or hydraulic hardware.
  • Remote automated control to alter physical machine speed or pressure settings.
  • Custom third-party ERP software modifications beyond standard data exports.
13

Current Known Limitations

  • Heavy metal machine structures require physical positioning adjustments for RFID reader antennas during installation.
  • High-temperature RFID tags attached to molds are designed for continuous operating temperatures up to 200°C.
  • Cloud synchronization speed is dependent on the plant's external internet connection speed.
14

Acceptance Criteria

  1. The machine controller accurately records production cycles and machine operational signals.
  2. Industrial RFID readers automatically detect high-temperature mold tags (up to 200°C) when molds are installed.
  3. The Central Server successfully collects and stores real-time data from all connected factory floor machines.
  4. The cloud synchronization engine safely buffers data locally during internet downtime and syncs automatically when reconnected.
  5. The role-based website displays the live factory floor map, individual machine dashboards, and OEE metrics clearly.
  6. The system supports clear separation between Trial Run tracking and standard Production Run accounting.
  7. Mold cavity tracking accurately measures active versus blocked cavities per mold.
  8. Downtime reasons can be categorized and reviewed using visual production loss charts.
  9. Scheduled auto-reports (Shift, Day, Week, Month, Quarter, Year, Lifetime) are automatically delivered via Email and Telegram.
  10. Real-time Telegram alerts arrive instantly on mobile devices when major machine events or unexpected stoppages happen.
